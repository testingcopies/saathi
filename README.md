## 🚀 Running Locally

### Prerequisites
- Node.js (v16+) or any standard static HTTP server / browser.

### Start the Server
```bash
node serve.js
```
Then visit **[http://localhost:4173](http://localhost:4173)** in your browser.

Or simply open `index.html` directly in any modern browser.
